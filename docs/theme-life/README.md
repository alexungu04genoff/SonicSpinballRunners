# Theme Life review media

Open [index.html](index.html) in a browser. It works locally without a server, network, external fonts or libraries.

The package contains 21 six-second C/A/B clips, an approximately 35-second unlabeled recommended-state overview, the seven-theme contact sheet and selected camera, Retro, atmosphere and light comparisons. Clips are sampled intervals, not seamless loops. Playback starts only when requested.

All primary clips use normal gameplay angle/zoom with a camera-only right focus at `(570, 500)`. Gameplay stays frozen at the canonical Act spawn. Diagnostic stills and video posters show time 7.25 seconds; the six-second clips start at zero. The Wide view is a separate zoom-0.6 diagnostic. Production Retro remains the visual authority.

Recommendations: Green Hill C; Chemical Plant C; Rooftop Run A; Casino Night B; Sky Sanctuary A; Ice Cap C; Aquarium Park C. Every production registry entry remains C. Ice A/B intentionally retain C. Lava Reef is excluded.

Original MP4s are copied without re-encoding. Resized JPEG stills keep this review portable; no artistic recoloring was applied. The contact sheet uses matched 7.25-second source frames. [provenance.json](provenance.json) records capture hashes, deterministic-repeat results and source fingerprints. Full-resolution originals and complete receipts remain in ignored `test-results/theme-motion/`.

Capture-time performance CSVs are deliberately excluded. [performance.csv](performance.csv) and [performance.json](performance.json) contain the separate final timing run; [repeats.json](repeats.json) records the Casino/Sky repeats. [bakes.json](bakes.json) records the 105-file disk audit, and [validation.json](validation.json) preserves the baseline and focused results, including the excluded Lava cache failures. See the [engineering report](../THEME_LIFE.md) for methodology and limitations. Desktop evidence does not certify UHD 620 performance.
